This guide builds **hello-clock**, a bar widget that shows the local time and an optional date. You need OmniWM running, `omniwmctl` on your `PATH`, and a text editor. Enable the Workspace Bar in **Settings > Styles & Widgets** to see the result. Basic programming knowledge is enough; no Luau experience is required.

**Unreleased: OmniShell is available when building from `main`.** Before running the commands below, turn on **Settings > Advanced > Enable IPC**; IPC is off by default. See [CLI setup](/reference/cli/overview/#installation) if `omniwmctl` is not on your `PATH`.

## 1. Create the widget

For `<profile>` in the paths below, use the selected style's profile folder, such as `default` or `lake`. Before creating `hello-clock`, check both `~/.config/omniwm/shell/<profile>/widgets/hello-clock/` and `~/.config/omniwm/shell/widgets/hello-clock/`.

If the profile-local folder already exists, reuse it or choose another name; `shell init` leaves it intact. If the top-level folder contains `init.luau`, that override takes precedence over the profile-local copy. Edit the top-level widget and keep `settings.toml` beside it, or choose an unused name and use it for the command and every path below.

For a new widget, run:

```sh
omniwmctl shell init hello-clock
```

The command creates `~/.config/omniwm/shell/<profile>/widgets/hello-clock/init.luau` unless that destination folder already exists.

For the rest of this guide, `<widget-folder>` means the effective widget directory: `~/.config/omniwm/shell/<profile>/widgets/hello-clock` for a profile-local widget, or `~/.config/omniwm/shell/widgets/hello-clock` when reusing a top-level override. Substitute your chosen widget name if it differs from `hello-clock`. Open `<widget-folder>/init.luau` in your editor.

OmniShell calls the global `render(ctx)` function to get a UI tree. The starter also includes a `popout(ctx)` function; this clock does not need a popout, so replace the starter with the file in the next step.

`ui.row{ ... }` is Luau's shorthand for passing a table to `ui.row`. Named entries such as `gap` style the row; numbered entries are its children. `content[#content + 1]` appends a child, and `..` concatenates strings.

The widget reads localized `ctx.data.clock` and `ctx.data.date`. `interval = 60` requests minute updates for timed data. The `reserve` string keeps the time label's width stable as its characters change. `surface`, `accent`, and `secondaryForeground` are palette colors, so the widget follows the selected style's palette.

`ctx.select("settings", "date")` reads one option. The `~= false` check means “show the date unless explicitly disabled,” matching the option default below. See [context and data](/omnishell/reference/context-data/) and [layout and styling](/omnishell/reference/layout-styling/) for other choices.

```text

```

## 4. Put it on the bar

1. Open **Settings > Styles & Widgets > Bar**.
2. Select **Add Widget…**, choose **hello-clock**, and add it to the **Center** group.
3. Select the new widget to open its options.
4. Turn **Show date** off, then on.

You should see a clock symbol, the local time, and the date. Turning the option off removes only the date. The existing bar layout stays in place; you can remove the bundled clock separately if you prefer one time display.

Widgets created by `shell init` are stored in the selected profile; other profiles can inherit widgets from `default/widgets/`. To make a profile-local widget an override for every profile, move its folder into the top-level `shell/widgets/` folder. Placement and option values belong to each profile. See [profiles and palettes](/omnishell/configuration/profiles-palettes/).

## 5. Check edits and diagnostics

Change `gap = 8` to `gap = 12` and save. OmniShell watches widget files and reloads the widget; the spacing should change without restarting OmniWM. Restore the original value when finished.

```sh
omniwmctl query shell-widgets
```

Find `hello-clock` in the result and check its state and error. For editor completion, use `~/.config/omniwm/shell/omniwm.d.luau`; browse the same definitions in the [Luau reference](/omnishell/reference/).

## Troubleshooting

| Symptom | Check |
|---|---|
| The widget is missing | Enable the Workspace Bar, add `hello-clock` to a lane, and check its exact folder name and `init.luau` filename. |
| No options appear | Put `settings.toml` beside the effective `init.luau`, then check `shell-widgets` for metadata errors. |
| An edit fails to render | Read the reported error and fix that line; keep the global `render(ctx)` function. |
| The date stays hidden | Open this widget's options in the active profile and turn **Show date** on. |
